# ChronoRelic (时渊怀表)

A Minecraft **26.2** Fabric mod adding the **Chrono Watch** (`chronorelic:chrono_watch`) — an epic artifact capable of recording spatial-temporal anchors, rewinding player state with a sonic shockwave, and preventing fatal damage via Mixin interception.

## Features
- **Record Anchor (`Shift + Right-Click`)**: Saves current dimension, exact coordinates, viewing angles, health, and hunger.
- **Active Rewind (`Right-Click`)**: Unleashes a sonic shockwave knocking back nearby entities within 5 blocks, teleports back to the anchor, restores health/hunger, and clears all status effects (10s cooldown).
- **Passive Death Prevention**: Automatically triggers an emergency rewind when taking fatal damage while held anywhere in the inventory (45s cooldown).

## Requirements
- Minecraft `26.2`
- Fabric Loader `>=0.19.5`
- Fabric API (`26.2`)
